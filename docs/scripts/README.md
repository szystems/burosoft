# Scripts

Esta carpeta contiene todos los scripts de shell (.sh) utilizados para:

## Scripts de Creación
- `add_pa_routes.sh` - Agregar rutas PA
- `create_pa_controllers.sh` - Crear controladores PA

## Scripts de Verificación
- `check_all_pa_models_fields.sh` - Verificar campos de modelos PA
- `check_pa_models.sh` - Verificar modelos PA

## Scripts de Corrección de Modales
- `fix_add_modal_ids.sh` - Corregir IDs de modales
- `fix_all_pa_controller_fields.sh` - Corregir campos de controladores PA
- `fix_all_pa_modal_fields.sh` - Corregir campos de modales PA
- `fix_delete_modal_targets.sh` - Corregir targets de eliminación de modales
- `fix_modal_ids.sh` - Corregir IDs de modales
- `fix_modal_variables.sh` - Corregir variables de modales
- `fix_pa_modal_targets.sh` - Corregir targets de modales PA
- `fix_resolucion_modal_fields.sh` - Corregir campos de modales de resolución
- `fix_showaudiencia_pa_fields.sh` - Corregir campos de PA en show audiencia

## Scripts de Corrección de Includes
- `fix_pa_includes.sh` - Corregir includes PA
- `fix_remaining_pa_includes.sh` - Corregir includes PA restantes

## Scripts de Actualización
- `update_pa_modals.sh` - Actualizar modales PA
- `update_pa_modal_routes.sh` - Actualizar rutas de modales PA

## Scripts de Restauración
- `restore_pa_va_structure.sh` - Restaurar estructura PA/VA
